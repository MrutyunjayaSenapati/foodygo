# AI-Powered Food Ordering Platform

## Project Overview

Build a production-ready food ordering platform similar to Zomato or Swiggy.

The platform consists of:

* Customer Mobile App
* Delivery Partner Mobile App
* Restaurant Dashboard
* Admin Dashboard
* Backend API

The system should support real-world deployment and scalability for small to medium-sized cities.

---

# Core Principles

* Use TypeScript everywhere.
* Follow clean architecture.
* Use feature-based module organization.
* Prefer reusable components.
* Use shared packages for types and constants.
* Write maintainable and production-grade code.
* Avoid unnecessary abstractions.
* Keep business logic inside services.
* Controllers should remain thin.
* Use strict TypeScript configuration.

# Authentication Rules

## Customer

Supported Login Methods:

* Google Login
* Email and Password

Authentication Flow:

1. User authenticates.
2. Backend verifies credentials.
3. Backend generates JWT access token.
4. Backend generates refresh token.
5. Tokens are returned to the client.

Access Token:

* 15 minute expiry

Refresh Token:

* 30 day expiry

Store tokens in:

* expo-secure-store

Never store tokens in AsyncStorage.

# Coding Standards

Use:

* async/await
* dependency injection where useful
* repository pattern
* service layer pattern

Avoid:

* business logic in controllers
* duplicated types
* duplicated validation

All request validation must use Zod.

---

# Error Handling

Use centralized error middleware.

Return standardized responses.

Example:

{
"success": false,
"message": "Unauthorized"
}
